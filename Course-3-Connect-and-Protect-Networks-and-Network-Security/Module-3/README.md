# 🚨 Network Intrusions

A network intrusion occurs when an unauthorized user or malicious actor gains access to a network.

Common causes include:

- Weak authentication
- Unpatched systems
- Misconfigured devices
- Vulnerable applications
- Social engineering attacks

---

# 🌐 Denial-of-Service (DoS) Attacks

A **Denial-of-Service (DoS)** attack attempts to overwhelm a system or service, preventing legitimate users from accessing it.

### Characteristics

- Single attack source
- Floods network resources
- Reduces system availability
- Can exhaust CPU, memory, or bandwidth

---

# 🌍 Distributed Denial-of-Service (DDoS)

A **Distributed Denial-of-Service (DDoS)** attack uses multiple compromised devices (botnets) to flood a target with traffic.

### Common Effects

- Website outages
- Service disruption
- Network congestion
- Financial and reputational damage

### Mitigation Techniques

- Firewalls
- Load balancing
- Traffic filtering
- Rate limiting
- DDoS protection services

---

# 📊 Network Traffic Analysis

Network traffic analysis helps identify suspicious or malicious activity.

### Tools

- tcpdump
- Wireshark
- Packet analyzers

### Benefits

- Troubleshooting
- Threat detection
- Incident investigation
- Network monitoring

---

# 🐧 tcpdump

`tcpdump` is a command-line packet analyzer used to capture and inspect network traffic.

Common uses include:

- Capturing packets
- Troubleshooting connectivity
- Detecting suspicious traffic
- Investigating attacks
- Monitoring network communication

---

# 🎯 Packet Sniffing

Packet sniffing is the process of capturing and inspecting network packets.

### Legitimate Uses

- Network diagnostics
- Performance monitoring
- Security investigations

### Malicious Uses

- Credential theft
- Data interception
- Session hijacking
- Sensitive information disclosure

---

# 🎭 IP Spoofing

IP spoofing is a technique where an attacker forges the source IP address of network packets.

### Purposes

- Hide attacker identity
- Bypass security controls
- Launch DDoS attacks
- Conduct man-in-the-middle attacks

---

# 🔍 Network Interception Attacks

Network interception attacks involve capturing or modifying communications between devices.

Examples include:

- Packet sniffing
- IP spoofing
- Session hijacking
- Man-in-the-Middle (MITM) attacks

---

# 🛠 Defensive Strategies

Common methods used to defend networks include:

- Firewalls
- Intrusion Detection Systems (IDS)
- Intrusion Prevention Systems (IPS)
- VPNs
- Network segmentation
- Secure protocols
- Traffic monitoring
- Regular patch management
