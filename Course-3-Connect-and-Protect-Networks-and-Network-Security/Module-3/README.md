# 📖 Overview

This repository documents my completion of **Module 3: Secure Networks Against Attacks** from **Course 3 – Connect and Protect: Networks and Network Security** in the **Google Cybersecurity Professional Certificate**.

This module focuses on common network attacks, how attackers exploit network vulnerabilities, and the defensive techniques cybersecurity professionals use to protect systems. Topics include **Denial-of-Service (DoS) attacks, Distributed Denial-of-Service (DDoS) attacks, packet sniffing, IP spoofing, and network traffic analysis using `tcpdump`**.
