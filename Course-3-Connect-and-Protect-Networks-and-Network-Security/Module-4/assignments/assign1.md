## Questions and Answers

### Question 1

**Fill in the blank:** The _____ acts as an intermediary between software applications and computer hardware.

**Correct Answer:** ✅ Operating system

**Explanation:**  
The operating system (OS) manages communication between software applications and computer hardware. It provides the necessary interface for applications to use hardware resources such as memory, storage, and processors.

### Question 2

**Which of the following activities are security hardening tasks? (Select all that apply)**

**Correct Answers:**

- ✅ Making patch updates
- ✅ Disposing of hardware and software properly
- ✅ Enforcing password policies

**Incorrect Answer:**

- ❌ Exploiting an attack surface

**Explanation:**  
Security hardening strengthens systems by reducing vulnerabilities and minimizing the attack surface. Common hardening tasks include:

- Applying security patches and updates.
- Properly removing outdated hardware and software.
- Enforcing strong password requirements.

---

### Question 3

**True or False:** Multifactor authentication (MFA) is a security measure that requires a user to verify their identity in at least two ways before accessing a system or network.

**Correct Answer:** ✅ True

**Explanation:**  
MFA improves security by requiring multiple forms of authentication, such as:

- Something the user knows (password or PIN).
- Something the user has (security token or mobile device).
- Something the user is (biometric verification).

---

### Question 4

**What are examples of physical security hardening? (Select all that apply)**

**Correct Answers:**

- ✅ Installing security cameras
- ✅ Hiring security guards

**Incorrect Answers:**

- ❌ Removing or disabling unused applications
- ❌ Reducing access permissions across devices

**Explanation:**  
Physical security hardening protects physical locations and equipment. Examples include:

- Installing security cameras.
- Employing security guards.
- Controlling physical access to facilities.

Removing applications and reducing device permissions are examples of software or access-control hardening, not physical security.
