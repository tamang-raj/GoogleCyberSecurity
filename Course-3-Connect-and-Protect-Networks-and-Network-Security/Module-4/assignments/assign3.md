## Questions and Answers

### Question 1

**Fill in the blank:** A key distinction between cloud and traditional network hardening is the use of a server baseline image, which enables security analysts to prevent _____ by comparing data in cloud servers to the baseline image.

**Correct Answer:** ✅ Unverified changes

**Explanation:**  
A server baseline image provides a trusted reference configuration. By comparing current cloud server data to this baseline, security analysts can quickly identify and prevent unauthorized or unverified changes that may indicate a security compromise.

---

### Question 2

**True or False:** Data and applications on cloud networks do not need to be separated based on their service category, such as their age or internal functionality.

**Correct Answer:** ✅ False

**Explanation:**  
Similar to operating system hardening, cloud environments should separate applications and data based on their service category. Examples include:

- Older applications separated from newer applications.
- Internal services isolated from front-end applications.
- Sensitive workloads separated from less critical services.

This segmentation improves security and limits the impact of potential attacks.

---

### Question 3

**Who is responsible for ensuring the safety of cloud networks? (Select all that apply)**

**Correct Answers:**

- ✅ Security team
- ✅ Cloud service provider (CSP)
- ✅ Individual users

**Explanation:**  
Cloud security is a shared responsibility. Cloud Service Providers secure the cloud infrastructure, while organizations, security teams, and users are responsible for protecting their data, applications, accounts, and properly configuring cloud services.

---

### Question 4

**Fill in the blank:** _____ cloud services are a common source of cloud security issues.

**Correct Answer:** ✅ Misconfigured

**Explanation:**  
Misconfigured cloud services are one of the leading causes of cloud security incidents. Incorrect permissions, exposed storage, and improperly configured resources can create vulnerabilities that attackers may exploit.
