## Questions and Answers

### Question 1

**Fill in the blank:** Security teams can use _____ to examine network logs and identify events of interest.

**Correct Answer:** ✅ Security Information and Event Management (SIEM) tools

**Explanation:**  
SIEM tools collect, analyze, and correlate log data from multiple systems, allowing security teams to monitor network activity, detect suspicious events, and respond to security incidents.

---

### Question 2

**What is a basic principle of port filtering?**

**Correct Answer:** ✅ Allow ports that are used by normal network operations.

**Explanation:**  
Port filtering follows the principle of allowing only the ports required for legitimate network operations while blocking unused or unnecessary ports. This reduces the attack surface and limits opportunities for attackers to exploit open ports.

> ❌ **Selected Answer:** Allow users access to only areas of the network that are required for their role.  
> This describes the **Principle of Least Privilege**, not port filtering.

---

### Question 3

**A security professional creates different subnets for the various departments in their business, ensuring users have access appropriate for their roles. What does this scenario describe?**

**Correct Answer:** ✅ Network segmentation

**Explanation:**  
Network segmentation divides a network into isolated subnets, limiting access between departments and improving security by containing potential threats.

---

### Question 4

**True or False:** Data in restricted zones should have the same encryption standards as data in other zones.

**Correct Answer:** ✅ False

**Explanation:**  
Restricted zones contain highly sensitive or confidential information and should use stronger encryption standards than other areas of the network to provide additional protection against unauthorized access.
