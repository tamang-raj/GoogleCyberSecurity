## Questions and Answers

### Question 1

**Fill in the blank:** ____ is the process of strengthening a system to reduce its vulnerability and attack surface.

**Correct Answer:** ✅ Security hardening

---

### Question 2

**When performing security hardening, what is the goal with regards to the attack surface?**

**Correct Answer:** ✅ Reduce the attack surface

---

### Question 3

**Fill in the blank:** Installing security cameras is an example of a _____ security hardening practice.

**Correct Answer:** ✅ Physical

---

### Question 4

**An organization's in-house security team has been authorized to simulate an attack on the organization's website to identify vulnerabilities. What does this scenario describe?**

**Correct Answer:** ✅ Penetration testing

---

### Question 5

**Which of the following are OS hardening tasks? (Select three)**

**Correct Answers:**

- ✅ Implementing multifactor authentication (MFA)
- ✅ Regularly installing updates
- ✅ Using secure encryption standards

---

### Question 6

**A security analyst compares firewall documentation with the current firewall configuration to ensure no changes have been made. What does this scenario describe?**

**Correct Answer:** ✅ Checking baseline configuration

---

### Question 7

**Which OS hardening practice requires users to verify their identity in two or more ways to access a system or network?**

**Correct Answer:** ✅ Multi-factor authentication (MFA)

---

### Question 8

**Which statement accurately describes port filtering?**

**Correct Answer:** ✅ A firewall function that blocks or allows certain port numbers in order to limit unwanted network traffic.

---

### Question 9

**A security team separates a highly restricted network zone from the rest of the network and applies stronger encryption standards. What does this scenario describe?**

**Correct Answer:** ✅ Network segmentation

---

### Question 10

**How can a security professional confirm that no unverified changes have occurred within a cloud server?**

**Correct Answer:** ✅ Compare the server baseline image to the data in cloud servers.
