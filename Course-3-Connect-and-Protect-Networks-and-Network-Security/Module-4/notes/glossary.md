# Course 3 - Module 4: Key Terms and Definitions

## Overview

This document summarizes the essential cybersecurity terms introduced in **Course 3, Module 4**. These concepts focus on security hardening, operating system security, authentication, vulnerability management, and network monitoring.

---

## Glossary

### Baseline Configuration (Baseline Image)

A **baseline configuration** is a documented set of system specifications used as the standard reference for future system builds, releases, and updates. It helps maintain consistency and detect unauthorized changes.

**Purpose:**
- Standardizes system configurations.
- Simplifies deployment and maintenance.
- Supports security auditing and compliance.

---

### Hardware

**Hardware** refers to the physical components of a computer system.

**Examples:**
- CPU (Processor)
- Memory (RAM)
- Hard drives and SSDs
- Motherboard
- Keyboard and mouse
- Network interface cards

---

### Multi-Factor Authentication (MFA)

**Multi-Factor Authentication (MFA)** is a security mechanism that requires users to verify their identity using two or more authentication factors before gaining access to a system or network.

**Common Authentication Factors:**
- Something you know (password or PIN)
- Something you have (security token or smartphone)
- Something you are (fingerprint or facial recognition)

**Benefits:**
- Provides stronger account protection.
- Reduces the risk of unauthorized access.
- Helps prevent credential-based attacks.

---

### Network Log Analysis

**Network log analysis** is the process of examining network logs to identify important events, suspicious activities, and potential security incidents.

**Benefits:**
- Detects abnormal network behavior.
- Supports incident investigations.
- Improves threat detection.
- Assists with security monitoring.

---

### Operating System (OS)

An **Operating System (OS)** is the software interface between computer hardware and the user. It manages system resources and enables applications to run.

**Examples:**
- Windows
- Linux
- macOS
- Android
- iOS

**Responsibilities:**
- Hardware management
- Memory management
- Process management
- File management
- User interface

---

### Patch Update

A **patch update** is a software or operating system update that fixes security vulnerabilities, corrects bugs, and improves system performance.

**Benefits:**
- Fixes known security flaws.
- Improves system stability.
- Protects against newly discovered threats.
- Keeps software up to date.

---

### Penetration Testing (Pen Test)

**Penetration testing (pen testing)** is a simulated cyberattack performed to identify vulnerabilities in systems, networks, websites, applications, or processes before attackers can exploit them.

**Benefits:**
- Identifies security weaknesses.
- Evaluates existing security controls.
- Helps prioritize remediation efforts.
- Strengthens overall cybersecurity.

---

### Security Hardening

**Security hardening** is the process of strengthening systems by reducing vulnerabilities and minimizing the attack surface through secure configurations, updates, and security controls.

**Common Hardening Practices:**
- Installing security patches.
- Removing unnecessary software and services.
- Enforcing strong authentication.
- Restricting user permissions.
- Configuring firewalls securely.

---

### Security Information and Event Management (SIEM)

A **Security Information and Event Management (SIEM)** system collects, correlates, and analyzes log data from multiple sources to monitor critical activities and assist security teams in detecting and responding to threats.

**Key Features:**
- Centralized log collection.
- Real-time event monitoring.
- Threat detection and correlation.
- Security alert management.
- Incident response support.

---

### World-Writable File

A **world-writable file** is a file that can be modified by any user on the system, regardless of ownership or permissions.

**Security Risks:**
- Unauthorized file modification.
- Potential malware injection.
- Data corruption.
- Privilege escalation opportunities.

**Best Practice:**
- Restrict write permissions to authorized users only.
- Regularly audit file permissions to identify and correct insecure settings.

---

## Summary

These foundational cybersecurity terms are essential for understanding system security and defense strategies. Concepts such as **security hardening**, **patch management**, **penetration testing**, **MFA**, **SIEM**, and **baseline configurations** help organizations reduce vulnerabilities, strengthen authentication, monitor network activity, and maintain secure computing environments.
