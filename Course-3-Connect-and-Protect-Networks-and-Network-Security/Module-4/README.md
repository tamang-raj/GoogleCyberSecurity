# 📖 Overview

This repository documents my completion of **Module 4: Security Hardening** from **Course 3 – Connect and Protect: Networks and Network Security** in the **Google Cybersecurity Professional Certificate**.

This module focuses on **security hardening**—the process of reducing vulnerabilities and strengthening the security of operating systems, networks, and cloud environments. It also introduces the application of the **NIST Cybersecurity Framework** in responding to security incidents through a portfolio activity.
