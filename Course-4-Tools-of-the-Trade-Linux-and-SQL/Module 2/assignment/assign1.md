# Question 1

## Question

**As a security analyst, you might use Linux to review logs when investigating an issue.**

### Options

- ✅ **A. True** *(Correct)*
  - Linux is widely used in cybersecurity for reviewing system logs, investigating security incidents, verifying user permissions, and monitoring system activity.

- ❌ **B. False**
  - This is incorrect because reviewing logs is one of the most common tasks security analysts perform on Linux systems.

### Why the Correct Answer?

Linux provides powerful command-line tools (such as `cat`, `less`, `grep`, `tail`, and `journalctl`) that allow security analysts to examine logs, troubleshoot problems, and detect suspicious activities.

### Key Concept

Security analysts commonly use Linux for:

- Reviewing logs
- Monitoring systems
- Verifying user access and permissions
- Incident response
- Running security and forensic tools

# Question 2

## Question

**Which of the following are components of the Linux architecture?** *(Select all that apply.)*

### Options

- ✅ **A. The kernel** *(Correct)*
  - The kernel is the core of Linux. It manages memory, processes, hardware devices, and system resources.

- ✅ **B. Applications** *(Correct)*
  - Applications are programs that perform tasks such as editing files, browsing the web, or running security tools.

- ✅ **C. The shell** *(Correct)*
  - The shell is the command-line interpreter that accepts user commands and communicates with the kernel.

- ❌ **D. The operating system**
  - This is incorrect because Linux **is** the operating system. The kernel, shell, applications, users, hardware, and filesystem are **components** that make up the operating system rather than separate components of Linux architecture.

### Why the Correct Answers?

Linux architecture is made up of multiple layers that work together:

1. User
2. Applications
3. Shell
4. Filesystem Hierarchy Standard (FHS)
5. Kernel
6. Hardware

Among the options provided, only **Kernel**, **Applications**, and **Shell** are actual components.

### Key Concept

Remember the Linux architecture in this order:

```
User
   ↓
Applications
   ↓
Shell
   ↓
Kernel
   ↓
Hardware
```

The Filesystem Hierarchy Standard (FHS) supports the system by organizing files and directories.

# Question 3

## Question

**Fill in the blank:**

The Filesystem Hierarchy Standard (FHS) is the component of Linux architecture that _____.

### Options

- ❌ **A. Manages processes and memory**
  - This is the responsibility of the **Kernel**.

- ❌ **B. Enables people to communicate with the system**
  - This describes the **Shell**, which serves as the interface between the user and the operating system.

- ✅ **C. Organizes data** *(Correct)*
  - The FHS defines how directories and files are organized in Linux, making the system consistent across distributions.

- ❌ **D. Consists of the physical components of a computer**
  - This describes **Hardware**, not the FHS.

### Why the Correct Answer?

The **Filesystem Hierarchy Standard (FHS)** specifies where files should be stored, making Linux systems easier to manage and navigate.

Examples include:

| Directory | Purpose |
|-----------|---------|
| `/home` | User files |
| `/etc` | Configuration files |
| `/bin` | Essential commands |
| `/var` | Log and variable data |
| `/tmp` | Temporary files |

### Key Concept

**FHS = File Organization**

Think of the FHS as the filing system of Linux.

# Question 4

## Question

**Which of the following hardware components are peripheral devices?** *(Select all that apply.)*

### Options

- ❌ **A. CPU**
  - The CPU (Central Processing Unit) is **internal hardware**. It performs calculations and executes program instructions.

- ❌ **B. RAM**
  - RAM (Random Access Memory) is also **internal hardware**. It temporarily stores data that the CPU is actively using.

- ✅ **C. Monitor** *(Correct)*
  - A monitor is an **output peripheral device** that displays information generated by the computer.

- ✅ **D. Printer** *(Correct)*
  - A printer is an **output peripheral device** that produces physical copies of digital documents.

### Why the Correct Answers?

Peripheral devices are **external hardware** connected to a computer to provide input, output, or additional functionality.

### Internal Hardware

These components are inside the computer and are necessary for its operation.

Examples:

- CPU
- RAM
- Motherboard
- SSD/HDD
- GPU

### Peripheral Devices

These devices connect to the computer externally.

Examples:

- Monitor
- Printer
- Keyboard
- Mouse
- Webcam
- Speakers
- Scanner
- Microphone

### Key Concept

A simple way to remember:

- **Internal Hardware** = Inside the computer (CPU, RAM, Motherboard)
- **Peripheral Devices** = Connected to the computer (Monitor, Keyboard, Mouse, Printer)
