# 📖 Overview

This repository contains my notes, exercises, and learning resources for **Module 1: Introduction to Operating Systems** from **Course 4 – Tools of the Trade: Linux and SQL** in the **Google Cybersecurity Professional Certificate**.

In this module, I explored the role of operating systems in managing computer hardware and software resources. I learned how operating systems allocate resources, process user requests, support virtualization, and provide different user interfaces such as the Graphical User Interface (GUI) and Command-Line Interface (CLI). These concepts form the foundation for working with Linux systems in cybersecurity.
