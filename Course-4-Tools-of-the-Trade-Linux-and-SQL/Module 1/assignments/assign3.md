# User Interfaces Quiz Answers

## Question 1

**What is a GUI?**

- ❌ A user interface that allows people to interact with a computer through commands
- ❌ A user interface that only runs on mobile devices
- ❌ A user interface that runs only on Linux operating systems
- ✅ **A user interface that enables people to manage tasks on a computer using icons**

**Explanation:**  
A **GUI (Graphical User Interface)** allows users to interact with a computer using visual elements such as icons, windows, menus, and buttons. Most operating systems support GUI-based interaction.

---

## Question 2

**Which of the following can be components of a GUI?** *(Select all that apply.)*

- ❌ Hardware
- ✅ **Desktop icons and shortcuts**
- ✅ **Task bar**
- ✅ **Start menu**

**Explanation:**  
Common GUI components include:

- **Desktop icons and shortcuts** – Provide quick access to applications, files, and folders.
- **Task bar** – Displays running applications and system shortcuts.
- **Start menu** – Provides access to programs, settings, and system features.

Hardware is not a GUI component because it refers to the physical parts of a computer.

---

## Question 3

**Fill in the blank: A security professional uses a(n) _____ to interact with a computer using text-based instructions.**

- ✅ **CLI**
- ❌ text system
- ❌ GUI
- ❌ operating system

**Explanation:**  
A **CLI (Command-Line Interface)** allows users to interact with a computer by entering text-based commands. Security professionals often use CLIs because they provide powerful tools for automation, investigation, and system management.

---

## Question 4

**A useful feature of a CLI is that it records a history file of commands and actions.**

- ✅ **True**
- ❌ False

**Explanation:**  
A CLI can store a history of previously executed commands. This helps security analysts:

- Review commands they have used.
- Verify actions during investigations.
- Troubleshoot problems.
- Trace possible attacker activity.
