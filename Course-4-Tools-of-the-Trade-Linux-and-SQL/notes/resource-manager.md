# Operating System as a Resource Manager

An **Operating System (OS)** is responsible for managing a computer's resources. It ensures that hardware resources are distributed efficiently so multiple applications and processes can run smoothly.

---

# OS as a Resource Manager

The operating system acts as the computer's **resource manager**, balancing the use of hardware resources among all running programs.

Just as a person manages their energy throughout the day for different activities, the OS manages the computer's available resources to ensure every application gets what it needs.

### Responsibilities of the OS

- Manages CPU usage.
- Allocates memory (RAM).
- Controls storage access.
- Manages input and output (I/O) devices.
- Ensures multiple programs can run efficiently at the same time.

---

# The Operating System as an Orchestra Conductor

A useful analogy is to think of the operating system as the **conductor of an orchestra**.

Just as a conductor coordinates different musicians to create harmonious music, the operating system coordinates hardware resources so every program runs efficiently.

### The OS Directs

- CPU time
- Memory allocation
- Storage access
- Input/output operations

Without the operating system, programs would compete for resources without coordination, causing conflicts and poor performance.

---

# Resource Allocation

Every running application requires system resources.

Common resources include:

- **CPU** – Executes instructions and performs calculations.
- **Memory (RAM)** – Stores data and programs currently in use.
- **Storage** – Saves files, applications, and operating system data.
- **Input/Output (I/O)** – Manages communication with devices such as keyboards, mice, printers, displays, and network interfaces.

Since these resources are limited, the operating system must decide:

- Which program receives resources.
- How much each program receives.
- When resources should be released for use by other programs.

This process is known as **resource allocation**.

---

# Resource Monitoring

Applications are constantly competing for limited system resources.

The operating system continuously monitors:

- CPU usage
- Memory usage
- Storage activity
- Input/output operations

Based on current demand, it allocates and deallocates resources to keep the computer running efficiently.

Most of this management happens automatically and is invisible to the user.

---

# Viewing Resource Usage

Although the operating system manages resources behind the scenes, users can monitor resource usage with system utilities such as:

- **Task Manager** (Windows)
- **Activity Monitor** (macOS)
- **System Monitor**, **top**, or **htop** (Linux)

These tools display information such as:

- Running processes
- CPU utilization
- Memory consumption
- Disk activity
- Network usage

---

# Key Concepts

- The operating system is responsible for managing all computer resources.
- Programs compete for CPU, memory, storage, and I/O resources.
- The OS allocates and deallocates resources to maximise efficiency.
- Resource management is performed automatically in the background.
- Monitoring tools allow users to view how system resources are being used.

---

# Key Takeaways

- The operating system acts as the computer's **resource manager**.
- It balances hardware resources among multiple running applications.
- Like an orchestra conductor, the OS coordinates all system components to work together efficiently.
- The OS continuously monitors and manages CPU, memory, storage, and I/O resources.
- Tools such as **Task Manager**, **Activity Monitor**, and **System Monitor** let users observe how resources are being utilised.
