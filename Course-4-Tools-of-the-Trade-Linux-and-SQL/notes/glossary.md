# Course 4, Module 1: Key Terms and Definitions

## Application

**Definition:**  
A program that performs a specific task.

**Example:**  
A calculator app, web browser, or word processor.

---

## Basic Input/Output System (BIOS)

**Definition:**  
A microchip that contains loading instructions for the computer and is commonly found in older systems.

**Purpose:**
- Starts the computer during the boot process.
- Checks hardware components.
- Loads the bootloader.

---

## Bootloader

**Definition:**  
A software program that boots the operating system.

**Purpose:**
- Loads the operating system into memory.
- Allows the computer to start functioning after power-on.

---

## Command-Line Interface (CLI)

**Definition:**  
A text-based user interface that uses commands to interact with the computer.

**Purpose:**
- Allows users to control the system through typed instructions.
- Provides powerful tools for automation and system management.

---

## Graphical User Interface (GUI)

**Definition:**  
A user interface that uses icons on the screen to manage different tasks on the computer.

**Common Components:**
- Desktop icons
- Shortcuts
- Taskbar
- Start menu
- Windows and menus

---

## Hardware

**Definition:**  
The physical components of a computer.

**Examples:**
- CPU
- RAM
- Storage devices
- Keyboard
- Monitor

---

## Legacy Operating System

**Definition:**  
An operating system that is outdated but is still being used.

**Risks:**
- May no longer receive security updates.
- Can contain unpatched vulnerabilities.
- May not be supported by the manufacturer.

---

## Operating System (OS)

**Definition:**  
The interface between computer hardware and the user.

**Responsibilities:**
- Manages hardware resources.
- Allows applications to run efficiently.
- Provides a way for users to interact with the computer.

---

## Random Access Memory (RAM)

**Definition:**  
A hardware component used for short-term memory.

**Purpose:**
- Stores data and programs currently being used.
- Allows the CPU to access information quickly.

---

## Unified Extensible Firmware Interface (UEFI)

**Definition:**  
A microchip that contains loading instructions for the computer and replaces BIOS on modern systems.

**Purpose:**
- Initializes hardware during startup.
- Loads the bootloader.
- Provides improved features compared to BIOS.

---

## User Interface

**Definition:**  
A program that allows the user to control the functions of the operating system.

**Types:**
- Graphical User Interface (GUI)
- Command-Line Interface (CLI)

---

## Virtual Machine (VM)

**Definition:**  
A virtual version of a physical computer.

**Purpose:**
- Simulates computer hardware using software.
- Allows multiple operating systems to run on one physical machine.
- Provides isolated environments for testing and security tasks.

---
