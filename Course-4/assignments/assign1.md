# Operating Systems Quiz Answers

## Question 1

**What is an operating system?**

- ❌ A program for sending email
- ❌ A computer, smartphone, or tablet
- ❌ The physical components of a computer
- ✅ **The interface between the computer hardware and the user**

**Explanation:**  
An operating system (OS) is the interface between computer hardware and the user, allowing users to interact with the computer and manage hardware resources efficiently.

---

## Question 2

**Which of the following are operating systems?** *(Select all that apply.)*

- ✅ Android
- ✅ Windows
- ✅ Linux
- ❌ Smartphones

**Explanation:**  
Android, Windows, and Linux are operating systems. Smartphones are hardware devices that run an operating system.

---

## Question 3

**Which of the following statements correctly describe operating systems?** *(Select all that apply.)*

- ✅ Operating systems help people interact with computers.
- ✅ Computers run efficiently because of operating systems.
- ✅ Operating systems are able to run many applications at once.
- ❌ Operating systems are the physical components of a computer.

**Explanation:**  
Operating systems provide a user interface, manage system resources efficiently, and support multitasking. They are software, not physical hardware.

---

## Question 4

**Computers communicate in a language called binary, which consists of 0s and 1s.**

- ✅ True
- ❌ False

**Explanation:**  
Computers use binary (0s and 1s) as their fundamental language for processing and storing data.
